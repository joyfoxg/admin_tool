# ⌚ Galaxy Watch Shizuku Wi-Fi Bridge (Wear OS)

갤럭시 워치(Wear OS 4 / 5 / 6, Galaxy Watch 4~8)에서 단독으로 로컬 Wi-Fi 핫스팟(SoftAP)을 생성하여, 스마트폰에서 핫스팟을 켤 수 없는 환경에서도 스마트폰의 무선 디버깅(Shizuku)을 활성화할 수 있도록 돕는 전용 도구입니다.

---

## 🌟 주요 기능 (Key Features)

1. **원클릭 로컬 핫스팟 (Local-only SoftAP)**:
   - 셀룰러 테더링 데이터 소모 없이 순수 로컬 Wi-Fi 인터페이스를 1초 만에 실행.
   - 워치 화면에 생성된 **Wi-Fi SSID**와 **비밀번호** 표시.
2. **워치 배터리 보호 (Auto Timeout)**:
   - 5분 카운트다운 후 자동 핫스팟 종료 타이머 내장.
3. **Wear OS 최적화 원형 UI**:
   - Compose for Wear OS 기반 라운드 스크린 레이아웃.
   - 비밀번호 확인을 위한 화면 켜짐 유지(Keep Screen On) 처리.

---

## 🚀 사용 흐름

1. 갤럭시 워치에서 **[워치 Shizuku 브릿지]** 앱 실행 ➔ 큰 원형 **[시작]** 버튼 터치.
2. 워치 화면에 뜬 **Wi-Fi 이름**과 **비밀번호** 확인.
3. 스마트폰의 Wi-Fi 설정에서 워치 핫스팟 연결.
4. 스마트폰의 **[설정 > 개발자 옵션 > 무선 디버깅]** 켜기 ➔ 스마트폰의 **[Shizuku]** 앱 열고 **[시작]** 터치!
5. 폰의 Shizuku가 켜지면 워치 앱에서 **[중지]**를 누르거나 자동 종료 타이머로 완료.
